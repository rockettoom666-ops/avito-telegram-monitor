# Avito Telegram Monitor

Telegram-бот на Python для мониторинга новых объявлений Avito. Отправьте ссылку
поиска с городом и фильтрами, выберите интервал и получайте новые объявления
с главным фото, названием, ценой, описанием и прямой ссылкой.

При первой проверке бот запоминает текущую выдачу **без рассылки старых объявлений**.
История сохраняется в SQLite и используется после перезапуска.

## Возможности

- Несколько пользователей с раздельными поисками и историей.
- Пробный доступ: 24 часа и один поиск.
- «Старт»: два одновременных поиска на семь дней, 200 ₽ / 150 Stars.
- «Про»: пять поисков на семь дней, 350 ₽ / 250 Stars.
- «Навсегда»: один поиск, интервал от 15 минут, 100 ₽ / 75 Stars.
- Администраторы: бессрочный доступ, до `MAX_SUBSCRIPTIONS_PER_USER` поисков.
- Интервалы 2, 5, 10, 15, 30, 60 минут с учётом тарифа.
- `/list`: проверка сейчас, смена интервала, пауза, возобновление, удаление.
- Постоянный профиль Chromium и окно для ручной проверки Avito.
- Очередь доставки с повторными попытками и ротационные логи.

Рублёвые цены описывают существующие тарифы в коде. Для продажи цифровых услуг
в Telegram используйте Stars в соответствии с
[правилами Telegram](https://core.telegram.org/bots/payments-stars).

## Быстрый старт на Windows

Установите Python 3.12 и Git. Откройте PowerShell:

```powershell
git clone https://github.com/rockettoom666-ops/avito-telegram-monitor.git
cd avito-telegram-monitor
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\install.ps1
Copy-Item .env.example .env
notepad .env
```

Заполните `TELEGRAM_BOT_TOKEN`, полученный у `@BotFather`. Затем:

```powershell
.\.venv\Scripts\python.exe -m avito_bot
```

Нажмите Start в личном чате со своим ботом, отправьте `/id`. Внесите полученный
номер в `.env`, например `ADMIN_CHAT_IDS=123456789`, перезапустите бот.
В `/subscription` появится администраторский бессрочный доступ.

Запуск и остановка двойным щелчком: `старт/start_bot.bat` и `старт/stop_bot.bat`.
Полные инструкции Linux и автозапуска: [INSTALL.md](docs/INSTALL.md).

## Использование

1. Откройте поиск Avito, задайте город, товар, цену и нужные фильтры.
2. Скопируйте полный адрес страницы и отправьте боту.
3. Выберите интервал; бот сам добавит сортировку по новизне.
4. Дождитесь начальной синхронизации. Затем будут приходить новые объявления.

Один «поиск» означает одну одновременно отслеживаемую ссылку, а не число
проверок или уведомлений. Пример запроса для проверки: «MacBook air m1 16/512»,
Нижний Новгород.

Команды: `/start`, `/help`, `/id`, `/list`, `/status`, `/subscription`, `/buy`,
`/faq`, `/terms`, `/paysupport`. Отдельной веб-админки и команды `/admin` нет.

используйте [основной Linux-гайд](docs/INSTALL.md#linux-debianubuntu).

## Данные и проверка

По умолчанию база находится в `data/bot.sqlite3`, профиль —
`.runtime/avito-profile`, лог — `logs/bot.log`. Эти данные, `.env`, фотографии
локальных проверок, ключи SSH и персональный список прокси исключены из Git.
Для своей установки создайте `.env` из `.env.example`.

```powershell
.\.venv\Scripts\python.exe -m ruff check src tests
.\.venv\Scripts\python.exe -m pytest -q
```

GitHub Actions запускает эти проверки автоматически.

## Ограничения

Компьютер должен быть включён и подключён к интернету. Для видимого Chromium
нужна активная графическая сессия. На сервере без рабочего стола можно запускать
`AVITO_HEADLESS=true`, но пройти капчу в таком окне вручную нельзя.

Avito может вернуть 429 или потребовать проверку браузера. Бот распознаёт такую
страницу, пытается открыть кнопку запуска капчи и оставляет её решение человеку.
429/капча повторяются через выбранный интервал поиска; другие ошибки используют
увеличивающуюся задержку до 60 минут. Предупреждение о проверке отправляется не
чаще раза в шесть часов на поиск.

Отслеживается первая страница выдачи: при высокой скорости появления объявлений
между проверками возможны пропуски. Уведомления дедуплицируются по ID. При обрыве
связи после принятия сообщения Telegram, но до сохранения результата в SQLite,
повтор доставки всё же возможен.
