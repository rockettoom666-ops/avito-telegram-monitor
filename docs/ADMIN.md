# Настройка администраторов

Админ-доступ задаётся владельцем в `ADMIN_CHAT_IDS`. Отдельного сайта,
пароля админки или команды `/admin` в проекте нет.

## 1. Узнать свой Telegram ID

Запустите бота с заполненным `TELEGRAM_BOT_TOKEN`, откройте с ним **личный чат**,
нажмите Start и отправьте `/id`. Бот вернёт числовой ID вашего аккаунта.
Не используйте вместо ID `@username`, номер телефона или ID самого бота.

## 2. Записать ID в настройки

Откройте `.env` в корне проекта:

```dotenv
ADMIN_CHAT_IDS=123456789
MAX_SUBSCRIPTIONS_PER_USER=10
```

Несколько администраторов указываются через запятую:

```dotenv
ADMIN_CHAT_IDS=123456789,987654321
```

Если используете прежнюю системную установку в `/opt/avito-bot`, меняйте
`/etc/avito-bot.env`: именно этот файл читает её systemd-служба.
Не добавляйте чужие ID: они получат максимальный доступ без оплаты.

## 3. Перезапустить бот

**Windows:** остановите бот через `старт/stop_bot.bat`, затем запустите
`старт/start_bot.bat`. Если работаете в консоли, нажмите Ctrl+C и выполните:

```powershell
.\.venv\Scripts\python.exe -m avito_bot
```

**Linux с пользовательской службой из INSTALL.md:**

```bash
systemctl --user restart avito-bot
```

**Прежняя системная служба в /opt:**

```bash
sudo systemctl restart avito-bot
```

## 4. Проверить доступ

В личном чате отправьте `/subscription`. Должны появиться администраторский
тариф, постоянный доступ и лимит `MAX_SUBSCRIPTIONS_PER_USER` (по умолчанию 10).
Минимальный интервал администратора — две минуты.

После выбора тарифа администратору также доступна тестовая кнопка ЮKassa.
Тестовый токен провайдера проверяет сценарий без реального списания; с боевым
provider token эта кнопка создаёт настоящий платёж. Подробности —
[PAYMENTS.md](PAYMENTS.md).

Добавление в админы не создаёт фиктивных платежей. Покупка тарифа не отменяет
администраторские привилегии. Список синхронизируется при каждом старте бота.

## Снять админ-доступ

Удалите ID из `ADMIN_CHAT_IDS` и перезапустите бот. Вернутся обычные правила
пробного периода или ранее купленной подписки. Поиски и платёжная история
сохранятся; число проверяемых поисков будет ограничено действующим тарифом.

## Что администратор пока не может делать через Telegram

Просматривать список всех пользователей, вручную выдавать чужие подписки,
делать массовые рассылки и управлять чужими поисками — этих функций нет.
Текущее администрирование включает конфигурацию `.env`, доступ к логам,
резервному копированию и перезапуску процесса на своём компьютере.
